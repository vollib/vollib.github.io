Installation

Current Python package: vollib 1.0.7
Supports Python 3.9 through 3.12

Python

  • pip install -U vollib
  • Source and dependency notes
  • py_lets_be_rational

Deprecated Python Transition Package

  • pip install -U py_vollib installs the matching vollib release
  • Existing py_vollib.* imports continue to work during the transition
  • New code should install, depend on, and import from vollib

TypeScript / JavaScript

  • npm install @vollib/vollib
  • The package is published as an ES module and includes TypeScript declarations
  • lets-be-rational is installed automatically as a runtime dependency

Import the full package: 

import { blackScholes } from "@vollib/vollib";

Or import a focused submodule: 

import { black } from "@vollib/vollib/black";
import { blackScholesMerton } from "@vollib/vollib/blackScholesMerton";

The lower-level LetsBeRational TypeScript package can also be installed directly: 

npm install lets-be-rational

Legacy Python 2.7

  • pip install vollib==0.1.5
  • Legacy vollib source
  • lets_be_rational
  • Use only for pinned legacy Python 2.7 environments
